# Extension Icons

For now, you can use placeholder icons. Create three PNG files:

- `icon-16.png` (16x16 pixels)
- `icon-48.png` (48x48 pixels)
- `icon-128.png` (128x128 pixels)

## Quick Generate Icons

Use this online tool: https://www.favicon-generator.org/

Or create simple colored squares in any image editor with the annotation theme (yellow/green/blue gradient).

## Temporary Workaround

If you want to skip this for now, you can comment out the `icons` section in `manifest.json` and the extension will still load with a default icon.
