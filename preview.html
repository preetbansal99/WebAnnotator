The Principles of Web Architecture

The World Wide Web was designed as an information space, with the goal that it should be useful not only for human-human communication, but also that machines would be able to participate and help. One of the major obstacles to this has been the fact that most information on the Web is designed for human consumption.

A core principle is Generality. A Web node does not have to be a specific device; a Web link can point to anything. This flexible architecture allowed the Web to scale massively over the past few decades without requiring fundamental re-engineering of the standard protocols.

Another critical design choice is Decentralization. No single computer "controls" the network. To scale cleanly, there is no centralized registry of endpoints. Instead, the Domain Name System (DNS) provides a distributed ledger of routing information, allowing independent nodes to discover each other dynamically.

Ultimately, HTML became the linga-franca because of its simplicity and fault tolerance. Browsers are incredibly forgiving of malformed HTML, which significantly lowered the barrier to entry for early authors. While this led to a messy early-Web, it catalyzed rapid adoption across the globe.
